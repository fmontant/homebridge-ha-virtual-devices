# Contributing

Thank you for your interest in contributing to **Homebridge HA Virtual Devices**.

Contributions of all kinds are welcome, including bug reports, feature requests, documentation improvements and code contributions.

---

## Before You Start

Before opening an issue or submitting a pull request, please:

- Search existing issues to avoid duplicates.
- Make sure your proposal aligns with the project's goals.
- Read the project documentation.

---

## Reporting Issues

When reporting an issue, please include as much information as possible:

- Plugin version.
- Homebridge version.
- Node.js version.
- Home Assistant version.
- Operating system.
- Relevant logs.
- Steps to reproduce the issue.

Clear and reproducible reports help resolve problems more quickly.

---

## Suggesting Features

Feature requests are welcome.

Please explain:

- the problem you are trying to solve;
- the proposed solution;
- why the feature would benefit other users.

---

## Contributing Code

Before submitting a pull request:

- Follow the project's coding style.
- Keep changes focused on a single objective.
- Update the documentation when appropriate.
- Test your changes before submission.

---

## Documentation

Documentation improvements are always appreciated.

This includes:

- correcting errors;
- improving clarity;
- adding examples;
- translating documentation.

---

## Pull Requests

Pull requests should:

- address a single topic;
- include a clear description;
- reference related issues when applicable;
- be ready for review.

---

## Code of Conduct

Please be respectful and constructive in all interactions.

The goal is to maintain a friendly, collaborative and welcoming community.

---

## Thank You

Every contribution, large or small, helps improve the project.

Thank you for supporting **Homebridge HA Virtual Devices**.
