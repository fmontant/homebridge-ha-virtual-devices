# Contribuer

Merci de l'intérêt que vous portez à **Homebridge HA Virtual Devices**.

Toutes les formes de contribution sont les bienvenues, qu'il s'agisse de signalements de bugs, de propositions de nouvelles fonctionnalités, d'améliorations de la documentation ou de contributions au code.

---

## Avant de commencer

Avant d'ouvrir une issue ou de soumettre une Pull Request, merci de :

- rechercher si le sujet n'a pas déjà été signalé ;
- vérifier que votre proposition s'inscrit dans les objectifs du projet ;
- prendre connaissance de la documentation du projet.

---

## Signaler un problème

Lorsque vous signalez un problème, merci de fournir autant d'informations que possible :

- version du plugin ;
- version de Homebridge ;
- version de Node.js ;
- version de Home Assistant ;
- système d'exploitation ;
- journaux (logs) pertinents ;
- étapes permettant de reproduire le problème.

Des rapports précis et reproductibles permettent de résoudre les problèmes plus rapidement.

---

## Proposer une évolution

Les propositions d'amélioration sont les bienvenues.

Merci de préciser :

- le problème que vous souhaitez résoudre ;
- la solution proposée ;
- les bénéfices attendus pour les utilisateurs.

---

## Contribuer au code

Avant de soumettre une Pull Request :

- respectez le style de développement du projet ;
- limitez vos modifications à un objectif précis ;
- mettez à jour la documentation lorsque cela est nécessaire ;
- testez vos modifications avant leur soumission.

---

## Documentation

Les améliorations de la documentation sont toujours appréciées.

Cela comprend notamment :

- la correction d'erreurs ;
- l'amélioration de la clarté ;
- l'ajout d'exemples ;
- la traduction de la documentation.

---

## Pull Requests

Les Pull Requests doivent :

- traiter un seul sujet ;
- comporter une description claire ;
- faire référence aux issues concernées, le cas échéant ;
- être prêtes pour la revue de code.

---

## Code de conduite

Merci de rester respectueux, bienveillant et constructif dans tous vos échanges.

L'objectif est de préserver une communauté accueillante, collaborative et agréable pour tous.

---

## Remerciements

Chaque contribution, quelle que soit son importance, participe à l'amélioration du projet.

Merci de contribuer au développement de **Homebridge HA Virtual Devices**.
