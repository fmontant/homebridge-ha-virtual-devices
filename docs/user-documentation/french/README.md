# Documentation française

Bienvenue dans la documentation utilisateur française de **Homebridge HA
Virtual Devices**.

Cette documentation concerne l'utilisation du plugin. La documentation
consacrée à l'architecture interne, au développement, aux scripts et aux
processus de publication se trouve dans `docs/developer-documentation/`.

## Documentation utilisateur

-   [Guide utilisateur](guide-utilisateur.md) --- installation, choix
    Home Assistant/Matter, ajout d'un capteur Matter, catalogue et
    utilisation quotidienne.
-   [Dépannage](depannage.md) --- diagnostic des problèmes Home
    Assistant, Matter, HomeKit et du catalogue.

## Documentation générale du projet

À la racine du dépôt :

-   `README.md` --- présentation générale du projet ;
-   `README.fr.md` --- présentation française ;
-   `ROADMAP.md` et `ROADMAP.fr.md` --- feuille de route du projet.

## Version 2

La version 2 permet d'utiliser :

-   Home Assistant uniquement ;
-   Matter uniquement ;
-   Home Assistant et Matter simultanément.

Les appareils provenant de ces sources sont gérés dans le catalogue du
plugin.

## Pour les développeurs

Consultez `docs/developer-documentation/` pour l'architecture, les ADR,
les diagrammes, l'internationalisation et le toolkit de développement.
