# GitHub Release Template

Use this template for the GitHub Release created for a published version of Homebridge HA Virtual Devices.

The GitHub Release should summarize the delivered changes without replacing the CHANGELOG. It should remain factual, concise, and focused on the value of the release.

---

Briefly present the most important changes delivered in this release.

## Writing Rules

- Describe only changes included in the published version.
- Do not announce planned or future features.
- Do not duplicate the complete CHANGELOG.
- Keep technical details proportional to their relevance for users.
- Ensure the version described matches the npm package and GitHub Release.
