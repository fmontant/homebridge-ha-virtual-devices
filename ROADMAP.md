# Roadmap

This document outlines the planned evolution of **Homebridge HA Virtual Devices**.

It provides visibility into upcoming features and long-term objectives. The roadmap is intended for informational purposes only and may evolve over time.

---

## Current Release

**Version:** 1.2.x

Current development focuses on improving the user experience, strengthening the project's documentation, and preparing future functional enhancements.

---

## Short-term Goals

### User Interface

- Bulk device operations.
- Advanced search and filtering.
- Improved device details.
- Additional management tools.

### Home Assistant Integration

- Improved device discovery.
- Enhanced synchronization reliability.
- Additional configuration options.

### Documentation

- Complete user documentation.
- Complete developer documentation.
- Contribution guidelines.
- Release templates.

---

## Mid-term Goals

### New Sensor Types

Support for additional Home Assistant entities, including:

- Air Quality
- Carbon Dioxide (CO₂)
- Volatile Organic Compounds (VOC)
- Atmospheric Pressure
- Illuminance

### Diagnostics

- Enhanced diagnostics.
- Improved logging.
- Better troubleshooting tools.

---

## Long-term Goals

### Architecture

- Performance optimizations.
- Internal refactoring.
- Expanded automated testing.
- Improved maintainability.

### Ecosystem

- Continuous improvement of the Homebridge user experience.
- Expanded documentation.
- Community contributions.
- Long-term project sustainability.

---

## Notes

This roadmap is provided for planning purposes only.

Features, priorities and schedules may change as the project evolves.
